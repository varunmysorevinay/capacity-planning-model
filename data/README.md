# Sample data

Every dataset in this folder is **synthetic**. The numbers are constructed to be
representative of high-mix, low-volume assembly and to exercise the edge cases the
code is built to catch — starved stations, precedence locks, long-tail downtime,
overloaded workcenters.

Nothing here is production data from any employer, past or present, and no
proprietary drawing, routing, cost, or customer information appears in this
repository. The datasets exist so the tools are runnable the moment you clone them.

Point the tools at your own CSVs to get real answers.
